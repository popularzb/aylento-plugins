# AYLENTO client 0.13.0-beta.3

本次更新改进客户端分发，核心 MCP 运行版本仍为 0.13.0-beta.1，36 项工具及服务端功能保持原有版本。

- Add GitHub Actions validation and version-tag release packaging.
- Prepare a self-contained npm package and official MCP Registry metadata.
- Expand the Claude plugin listing with installation, capabilities, support and data-handling documentation for directory review. Official directory approval remains pending.
- Add direct Gemini CLI Git installation/update instructions and correct outdated review-only license wording.
- Keep AYLENTO Client Use License v1.0 and bundled third-party notices.
- Preserve authorization, profile and local history during upgrades.

Download the complete `aylento-plugins-0.13.0-beta.3.zip` for native plugin catalogs, or the `.tgz` for a standalone local MCP client. Node.js 24.15.0 or newer is required. See README.md and HOSTS.md for host compatibility and verification limits.

GitHub download availability does not imply npm publication or directory approval. npm and MCP Registry publishing activate only after publisher setup. Consult the workflow run and each destination for its actual status.
